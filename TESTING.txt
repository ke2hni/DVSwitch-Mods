DVSwitch-Mods dashboard-targets 1.2.0 test update

This updates the existing dashboard-targets component. Files belong at their
existing repository paths; there is no new runtime mod or service.

On pi4test, then pi5test, then node3040, run:

cd ~/DVSwitch-Mods && git pull --ff-only && PYTHONDONTWRITEBYTECODE=1 python3 tests/test-dashboard-targets.py && sudo ./mod-dashboard-targets.sh --check

If the test and --check pass, install with:

sudo ./mod-dashboard-targets.sh --install

The installer backs up and upgrades the existing target display helper. It
does not need to rewrite lh.php or localtx.php when those patches are already
present. The PHP runtime test covers a D-Star CQCQCQ row linked to REF030 C,
a later link change to REF090 B, and a subsequent disconnect; it also queries
the older event after the newer one to ensure history retains REF030 C.

After the first test node passes, continue in order. Do not modify production
node68425 until the test nodes pass and production changes are explicitly
authorized.
